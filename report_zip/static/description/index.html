Zip Report Actions

Generate ZIP archives containing multiple reports in Odoo with advanced compression and encryption options

This module requires the Python library 'pyzipper' to be installed. Install it using pip install pyzipper.

Key Features

Multiple Reports

Combine multiple reports into a single ZIP archive

AES Encryption

Secure your reports with AES encryption support

Compression Options

Various compression options for optimal file size

Configuration Process

Step 1

Go to Settings > Technical > Reports

Step 2

Create or edit a report

Step 3

Select "Zipped report" type

Step 4

Add reports to include
